- 已安装并打开「微信开发者工具」
- 项目已经导入开发者工具，且能正常预览
- 云环境是 `cloud1-d5gievact76bc75a4`（v2 方案里写的那个）

## 操作步骤

### ① 打开云开发控制台

微信开发者工具顶部菜单栏 → 点击「**云开发**」按钮（蓝色云朵图标）→ 弹出云开发控制台窗口。

### ② 切换到「数据库」标签

左侧菜单：**数据库** → 你会看到现有的集合列表（exam、subjects、questions、historys、notes、profiles）。

### ③ 新建 employees 集合

点击集合列表左上角的「**+**」按钮（添加集合）→ 输入集合名：

```
employees
```

→ 点确定。

### ④ 设置集合权限（重要！）

刚建好的集合默认权限是「仅创建者可读写」——这就是我们想要的。但保险起见检查一下：

- 点开 `employees` 集合 → 顶部「**权限设置**」标签
- 选择「**仅创建者可读写**」→ 保存
- 切忌选「所有用户可读」，那样普通员工能直接绕过云函数读员工表

### ⑤ 导入初始数据

- 点回「**数据**」标签
- 点击右上角「**导入**」按钮
- 选择文件：`D:\AI\AIProjects\exam-mini-master\docs\初始员工数据.json`
- 数据格式选：**JSON 行（每行一条记录）**
- 冲突处理：**插入新记录**
- 点「导入」

预期结果：左下角提示「成功导入 3 条记录」。

### ⑥ 校验导入结果

回到「数据」标签，刷新一下，应该能看到 3 条记录：

| name | dept | role | openid | activatedAt | active |
|---|---|---|---|---|---|
| 李妙言 | 项目部 | admin | (空) | null | true |
| 张三 | 运行检修部 | employee | (空) | null | true |
| 李四 | 综合管理部 | admin | (空) | null | true |

### ⑦（可选）建索引

- 顶部「**索引管理**」标签 → 新建索引
- 索引 1：`idx_openid`，字段 `openid`，升序，不勾选「唯一索引」
- 索引 2：`idx_name_dept`，字段 `name` 升序，`dept` 升序，不勾选「唯一索引」

> 数据量小（30 人）的情况下不建索引也能跑，但建了之后查询永远快。

## 常见踩坑

- **找不到「导入」按钮**：可能在右上角「…」三个点的菜单里。新版控制台 UI 略不同。
- **导入失败「文件格式错误」**：注意我给的 JSON 是「JSON 行」格式（每行一个对象，行尾**没有逗号**），不是 JSON 数组 `[...]`。导入时一定选「JSON 行」。
- **activatedAt 显示成空字符串而不是 null**：手动点开那条记录，把字段类型改成 null。或者忽略，不影响后续逻辑（云函数会兼容空字符串和 null）。
