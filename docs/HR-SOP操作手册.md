## 1. 首次准备

### 1.1 进入管理后台

1. 用微信打开小程序，完成员工激活（参见《员工端使用说明》）
2. 进入「我的」页面，确认已激活
3. 首页底部入口网格会出现「🛠 管理后台」图标（仅 HR / admin 可见）
4. 点击进入 HR 后台主页

> **如果看不到「管理后台」入口**：说明你的角色还是普通员工。首次启用需要管理员在云开发控制台手动设置（见 1.2）。

### 1.2 首位 admin 设置（仅首次）

第一位管理员需要手动设置，后续的 HR 可由管理员在小程序内直接升级。

1. 打开微信开发者工具 → 云开发控制台 → 数据库 → `employees` 集合
2. 找到自己的那条记录（按 `name` 字段查找）
3. 把 `role` 字段的值改为 `"admin"`（注意是小写，带引号）
4. 关闭小程序重新打开，首页即可看到「管理后台」入口

> **admin 与 HR 的区别**：admin 拥有 HR 的全部权限，额外可以访问「系统设置」（配置水印、单位名称）。日常运营设一个 admin 即可，其余管理岗设为 hr。

## 2. 系统设置

> 仅 admin 可见。用于配置 PDF 导出时的水印文字和单位名称。

### 2.1 进入路径

HR 后台主页 → 第 5 张卡片「⚙️ 系统设置」（仅 admin 可见）

### 2.2 配置项

| 配置项 | 说明 | 默认值 | 限制 |
|---|---|---|---|
| 水印文字 | PDF 半透明斜向水印的固定文字 | `基里隆项目部内部资料 · 严禁外传` | ≤ 60 字 |
| 单位名称 | PDF 落款处显示的单位名 | `中国安能集团第二工程局有限公司基里隆项目部` | ≤ 60 字 |

### 2.3 操作

1. 修改输入框内容（右上角有字符计数）
2. 点击「保存」
3. 如需恢复默认，点击「恢复默认」按钮

> 水印和单位名称对所有 PDF 导出统一生效，修改后已有的 PDF 不会变，仅影响后续导出。

## 3. 员工管理

### 3.1 进入路径

HR 后台主页 → 「👥 员工管理」

### 3.2 员工列表

列表展示全体员工，按激活时间倒序排列。每行显示：
- 姓名、部门、角色（employee / hr / admin 标签）
- 激活状态（正常 / 已停用）
- 每行两个操作按钮：「编辑」「删除」

### 3.3 操作说明

| 操作 | 说明 | 限制 |
|---|---|---|
| 编辑 | 进入编辑页修改部门、角色（employee/hr radio 选择）、启用/停用 | admin 行只读不可编辑 |
| 删除 | 从白名单移除该员工，历史成绩和答卷记录保留 | admin 行不可删；自己不可删自己（防自锁） |
| 📥 导入 | 从 CSV 文件批量导入员工白名单 | 姓名+部门重复自动跳过 |

**编辑页说明**：
- 点击「编辑」进入编辑页，可修改所属部门（picker）、角色（普通员工 / HR radio 勾选）、账号状态（正常 / 已停用 switch）
- 停用后员工无法登录（软删除），可随时重新启用
- admin 超管行全部字段只读，提示去云开发控制台修改

### 3.4 新员工激活流程

1. 新员工自行打开小程序，在激活页填写姓名 + 选择部门
2. 系统匹配 `employees` 表中的白名单记录，绑定微信身份
3. HR 在员工管理页可看到该员工已激活

> 白名单数据需要在云开发控制台 → `employees` 集合提前录入（姓名 + 部门）。可使用 `data/员工白名单模板.csv` 批量准备数据后导入。

## 4. 题库管理

### 4.1 进入路径

HR 后台主页 → 「📚 题库管理」

### 4.2 题库列表

题库按一级试卷分组展示。每张卡片显示：
- 题库 ID、题库名
- 题量分桶统计（总数 / 单选 / 多选 / 判断，用彩色标签区分）
- 三个操作按钮

### 4.3 操作说明

| 操作 | 说明 |
|---|---|
| 查看题目 | 进入该题库的题目列表 |
| 编辑 | 修改题库名称或所属一级试卷 |
| 删除 | **级联删除**该题库下所有题目 |

### 4.4 删除题库的规则

- **被考试引用时阻止删除**：如果已有考试使用了该题库，系统会弹窗列出所有引用的考试名，拒绝删除
- **无引用时允许删除**：先批量删除该题库下所有题目，再删除题库本身
- 删除前有二次确认弹窗，并提示将连带删除的题目数量

### 4.5 新建题库

1. 题库列表页右上角点击「+ 新建」
2. 填写题库 ID（只允许字母、数字、下划线、短横线，创建后不可改）
3. 填写题库名称
4. 选择所属一级试卷（下拉选择）
5. 点击「创建」

> 题库 ID 是后续录题、建考试时的关键标识，建议用有意义的命名（如 `safe_2026q2`）。

## 5. 题目录入

### 5.1 进入路径

题库管理 → 选择题库 → 「查看题目」→ 右上角「+ 新建」

### 5.2 三种题型

| 题型 | typecode | 选项要求 | 正确答案要求 |
|---|---|---|---|
| 单选 | 01 | ≥ 2 项 | 恰好 1 项正确 |
| 多选 | 02 | ≥ 2 项 | ≥ 2 项正确 |
| 判断 | 03 | 固定 2 项（A=正确 / B=错误） | 恰好 1 项正确 |

### 5.3 录入操作

1. **选择题型**：顶部下拉切换单选 / 多选 / 判断
2. **填写题干**：输入题目内容
3. **选项编辑**（动态行）：
   - 每行 = 选项编号圆徽（A/B/C/... 自动编号）+ 选项内容输入框 + 「设为正确」切换 + 「删」按钮
   - 点击「+ 添加选项」增加行（上限 8 项，下限 2 项）
4. **标记正确答案**：点击选项右侧的「设为正确」/「✓ 正确」切换
   - 单选：标记任一项会自动取消其他项（互斥）
   - 多选：可任意切换多项
   - 判断：固定 A=正确 / B=错误，内容只读
5. **解析**（可选）：填写题目解析，员工复盘时可见
6. 点击「保存」

### 5.4 题型切换的自动处理

| 切换方向 | 自动行为 |
|---|---|
| → 判断 | 强制重置为 2 项，A=正确 / B=错误，内容只读 |
| 多选 → 单选 | 自动只保留第一个正确项，避免「单选只能 1 个正确」报错 |
| 单选 → 多选 | 原正确项保留，可继续标记更多 |

### 5.5 校验规则

保存时前端 + 云函数双重校验，不通过会弹模态提示具体原因：
- 题库必须存在
- 题干必填
- 选项数 ≥ 2
- 选项编号（code）必须为大写字母且唯一
- 单选/判断恰好 1 个正确答案，多选 ≥ 2 个正确答案
- 判断题必须恰好 2 项

## 6. 新建考试

### 6.1 进入路径

HR 后台主页 → 「📋 考试管理」→ 右上角「+ 新建」

### 6.2 配置项

| 配置项 | 说明 | 示例 |
|---|---|---|
| 考试名称 | 显示在员工端考试通知卡 | `2026年7月摸底考试` |
| 题库 | 下拉选择（显示「题库名（一级试卷名）」） | `安全知识（安全培训）` |
| 开始日期 | date picker | `2026-07-15` |
| 开始时间 | time picker，右侧显示时区标签 | `20:00 UTC+7` |
| 时长（分钟） | 答题时长 | `60` |
| **有效期（小时）** | 开考后多少小时内可进场，1~168 | `48` |
| 单选 题数/分值 | 配置单选题量与每题分值 | `5 题 / 10 分` |
| 多选 题数/分值 | 配置多选题量与每题分值 | `3 题 / 15 分` |
| 判断 题数/分值 | 配置判断题量与每题分值 | `5 题 / 5 分` |
| 目标部门 | 点击展开部门列表，勾选参与考试的部门。默认全部勾选（全员） | 勾选项目部、运行检修部 |
| 列表可见 | 开关，关闭后员工端看不到 | 开 |
| 列表可见 | 开关，关闭后员工端看不到 | 开 |

### 6.3 有效期说明（重要）

有效期是 v0.4.2 引入的**个人计时模型**：

- **开考后**，员工在有效期（如 48 小时）内**随时可进场**
- 进场后才开始个人倒计时（如 60 分钟），**照常考完整时长**
- 有效期只管"能不能进场"，进场后允许超时答完
- 例：开考后 47 小时进场，仍可考完整 60 分钟

> **与旧模式的区别**：旧模式是全员统一截止（`startTime + duration`），进场晚=时间少。新模式解决了"因工作不能第一时间参考"的问题。

### 6.4 时区说明

- 开始时间右侧会显示绿色时区标签（如 `UTC+7`），自动从你的设备获取
- HR 在哪个时区设的时间，就是哪个时区的开考时间
- 员工端显示会自动转换为员工所在时区

### 6.5 题量校验

保存时云函数会预检题库存量：
- 按题型分桶统计题库中单选/多选/判断的实际数量
- 与配置的题量比对，**不足则拒绝创建**
- 弹模态对话框列出每个题型缺多少，例如：
  ```
  题库题量不足
  判断题：需要 5，仅有 2
  ```

### 6.6 编辑限制

- **进行中 / 候考中的考试**：可以编辑
- **已结束的考试**（到期或被提前结束）：**不可编辑**，点卡片会提示「该考试已结束，不可编辑」
- 服务端也有拦截，即使绕过前端也无法保存

## 7. 考试进行中

### 7.1 提前结束考试

考试管理列表中，每场考试有两个并排按钮：「成绩」和「结束」。

| 考试状态 | 「结束」按钮 |
|---|---|
| 候考中（未开考） | 可点击，红色 |
| 进行中（有效期内） | 可点击，红色 |
| 已截止 / 已隐藏 | **灰色禁用** |

**操作**：
1. 点击「结束」按钮
2. 弹出二次确认（红色确认键），提示「已交卷成绩不受影响」
3. 确认后考试立即变为已截止，员工无法再进场
4. 按钮即时变灰

**影响范围**：
- ✅ 已交卷的员工成绩**不受影响**
- ✅ 正在答题中的员工**不受影响**（允许考完）
- ❌ 尚未进场的员工**无法再进场**

> 提前结束后，考试不可再编辑（防止改时间"复活"）。

### 7.2 查看考试状态

考试管理列表每张卡片显示：
- 考试名、科目、开始时间、时长
- 题量、总分、已报名、已交卷 4 项统计
- 状态标签（候考中 / 进行中 / 已截止 / 隐藏）

## 8. 成绩中心

### 8.1 进入路径

考试管理 → 某场考试卡片 → 点击「成绩」按钮

### 8.2 成绩单概览

顶部显示考试信息卡（考试名 / 开考时间 / 时长 / 题量 / 满分 / 目标部门）。

Summary 卡显示 5 项统计：
- 应到（黑）/ 已交卷（绿）/ 答题中（橙）/ 缺考（灰）/ 平均分

### 8.3 名单与状态

4 个 tab 切换过滤：全部 / 已交卷 / 答题中 / 缺考

每行显示：
- 姓名 + 部门 + 角色 tag（HR / admin 高亮黄）
- 状态徽章（已交卷 / 答题中 / 缺考）
- 分数 `score / fullScore`
- 已交卷副行：答对题数 / 总题数 + 交卷时间；**切屏次数 > 0 时红色高亮**

### 8.4 单人复盘

1. 在成绩列表中点击已交卷的员工
2. 进入单人答卷复盘页
3. 顶部显示：姓名 / 部门 / 考试名 / 交卷时间 / 得分 / 答对题数 / 切屏次数
4. 题目导航网格：每题一个色块（绿=对 / 红=错），可点击直接跳到该题
5. 题卡展示：题干 / 选项三态高亮（绿=选对 / 红=选错 / 绿虚框=应选未选）/ 他的答案 / 正确答案 / 解析

> 切屏次数仅展示，没有"高切屏自动驳回"逻辑。如需复核，由 HR 人工判断。

## 9. PDF 导出

> 完全自研，不依赖任何第三方 PDF 库。水印 / 单位名称在「系统设置」配置。

### 9.1 导出总分单（一场考试一张表）

**入口**：成绩中心页 → 「📄 导出本场总分单」按钮

**内容**：
- 表头：序号 / 姓名 / 部门 / 状态 / 提交日期 / 分数
- 仅展示已交卷的员工
- 状态列：合格 / 不合格（按 80 分判）
- 末页落款：单位名 + 考试日期

### 9.2 导出单人答卷

**入口**：单人复盘页 → 「📄 导出答卷」按钮

**内容**：
- 首页头：考试名 + 姓名 / 部门 / 交卷时间 / 切屏次数 + 成绩行
- 每题：题干 + 选项四态染色 + 他的答案 / 正确答案 / 解析
- 末页落款：单位名 + 交卷日期（注意是员工交卷那天）

### 9.3 导出全员答卷（批量）

**入口**：成绩中心页 → 「📚 导出全员答卷」按钮

**内容**：
- 每人独立分页，换人强制翻页
- 全局连续页码
- 整本 PDF 末页一份落款
- 页脚随当前页所属员工切换

**注意**：
- 仅在「全部 / 已交卷」tab 且有已交卷数据时启用
- 超过 20 人时弹确认框（耗时较长）
- 导出过程有进度反馈

### 9.4 导出后操作

PDF 生成后自动打开预览，可通过右上角「…」菜单：
- 转发给微信好友
- 保存到手机

## 10. 常见问题

### Q1：新建考试时报「题库题量不足」

**原因**：题库中某题型的实际数量少于考试配置的数量。

**解决**：到题库管理 → 查看题目，补充对应题型的题目。弹窗会告诉你具体缺哪个题型缺多少。

### Q2：考试已结束，想修改时间重新开放

**不行**。已结束（到期或被提前结束）的考试不可编辑，这是防止数据混乱的设计。请新建一场考试。

### Q3：员工说看不到考试

排查清单：
1. 考试的「列表可见」开关是否打开
2. 员工的部门是否在「目标部门」范围内（全部勾选=全员可见）
3. 员工是否已激活
4. 考试是否已到开始时间（未开考的考试在候考页可见）

### Q4：员工说进不了考场

排查清单：
1. 是否在有效期内（开考后 validHours 小时内）
2. 是否已交过卷（同一人同一场只能考一次）
3. 是否在目标部门范围内
4. 账号是否被停用

### Q5：PDF 导出报错或水印不对

1. 检查「系统设置」中的水印文字和单位名称是否已配置
2. 确认自己是 admin 角色（系统设置仅 admin 可写）
3. PDF 预览需要微信支持 `wx.openDocument`，一般正常

### Q6：时区显示不对

- 开始时间右侧的时区标签（如 `UTC+7`）是从你的设备自动获取的
- 如果你在柬埔寨（UTC+7）设了 20:00 开考，在 UTC+8 设备上会显示 21:00，这是正确的
- 确保设时间的设备时区与你所在时区一致即可

### Q7：如何删除一场考试

当前版本不支持删除考试，只支持「提前结束」。已结束的考试会保留在列表中作为历史记录。如确实需要删除，请在云开发控制台 → `assessments` 集合手动删除。

### Q8：admin 忘记了自己是谁

在云开发控制台 → `employees` 集合，搜索 `role: "admin"` 即可找到所有管理员。如需重置，直接修改 `role` 字段。
