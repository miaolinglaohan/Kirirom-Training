# 员工端使用说明

> 面向全体参加考试的员工。看完本文档能完成：激活账号 → 查看考试 → 候考 → 答题 → 看成绩全流程。

---

## 1. 首次激活

### 1.1 打开小程序

用微信扫码或搜索打开「基里隆项目部培训考试系统」小程序。

### 1.2 填写激活信息

首次打开会跳转到激活页：

1. **输入姓名**：填写你的真实姓名（需与 HR 录入的白名单一致）
2. **选择部门**：从下拉列表选择你所在的部门
   - 项目部 / 运行检修部 / 综合管理部 / 枢纽管理部 / 安全技术部 / 财务资金部
3. 点击「提交」

### 1.3 激活失败怎么办

| 提示 | 原因 | 解决 |
|---|---|---|
| 未找到匹配的员工 | 姓名或部门与白名单不符 | 联系 HR 确认你的姓名和部门 |
| 该姓名有多个匹配 | 同部门有重名 | 联系 HR 处理 |
| 该账号已激活 | 你之前已经激活过 | 直接登录即可 |
| 账号已停用 | HR 停用了你的账号 | 联系 HR |

> 激活成功后无需重复操作，以后直接打开小程序即可使用。

---

## 2. 查看考试通知

### 2.1 首页考试卡片

打开小程序进入首页，顶部会显示当前最该关注的考试：

- **进行中**（绿色标签）：点击直接进入考场
- **未开考**（黄色标签）：点击进入候考页倒计时

### 2.2 考试安排页

首页点击「📅 考试安排」大按钮，可查看全部考试列表：

- 每场考试显示：名称 / 开考时间 / 答题时长 / 题量 / 满分 / 有效期
- 状态标签：未开考 / 进行中 / 已截止
- 进行中的考试可直接点击进入考场
- 未开考的考试点击进入候考页

---

## 3. 候考

### 3.1 进入候考页

从首页考试卡片或考试安排页，点击**未开考**的考试，进入候考页。

### 3.2 候考页显示内容

- 📢 考试名称
- 大号倒计时（时:分:秒，每秒刷新）
- 📅 开考时间
- ⏱ 答题时长
- 📝 题目数量
- 💯 满分
- ⏳ 有效期（开考后多少小时内可进场）
- 👥 目标部门

### 3.3 等待开考

- 倒计时归零前，底部按钮显示灰色「等待开考中…」，不可点击
- 倒计时归零后，按钮变绿显示「▶ 立即进入考场」
- **点击按钮**才会进入考场（不会自动跳转，你可以准备好再进）

> 倒计时基于服务端时间校准，修改手机系统时间无效。

---

## 4. 答题

### 4.1 进入考场

点击「立即进入考场」后，系统会：
1. 校验你是否在有效期内
2. 随机抽题（每人题目可能不同）
3. 固化题目到你的答卷快照（防止刷新换题）
4. 开始个人倒计时

### 4.2 答题界面

- 顶部进度条：已答 X / 共 Y 题
- 题目区域：题干 + 选项
  - **单选**：点选一个选项（圆形按钮）
  - **多选**：可点选多个选项（方形按钮）
  - **判断题**：两个大按钮「✓ 正确」「✗ 错误」
- 底部：上一题 / 下一题 / 题号跳转面板

### 4.3 自动暂存

- 每 30 秒自动保存你的作答
- 意外退出后重新进入，会恢复你之前的答案（续考）

### 4.4 ⚠ 切屏警告

- 答题过程中切换到其他 App 或退出小程序，系统会**记录切屏次数**
- HR 在复盘时能看到你的切屏次数
- 切屏次数过高可能被 HR 人工复核

### 4.5 交卷

**手动交卷**：点击「交卷」按钮，确认后提交

**自动交卷**：
- 倒计时归零自动交卷
- 剩余时间不足 1 分钟时页面闪红警告

### 4.6 防作弊机制

- ⏰ 倒计时基于**服务端时间**，改手机时间无效
- 🔒 答案不下发，交卷后服务端才判分
- 🎲 题目随机抽取，每人不同
- 🚫 同一人同一场考试只能考一次，交卷后不可重考

## 5. 看成绩

### 5.1 考试结果页

交卷后自动跳转到结果页：
- 顶部分数大图：得分 X / 满分 Y
- 三栏统计：答对 / 答错 / 总题数
- 模拟考试可展开「查看正确答案」

### 5.2 我的成绩

底部 Tab「📊 成绩」查看历史考试记录：
- 每条记录显示：考试名 / 得分 / 答对题数 / 考试时间
- 点击任意记录进入复盘

### 5.3 复盘

复盘页逐题展示：
- 题干
- 选项三态配色：
  - 🟢 绿色实底 = 你选对了
  - 🔴 红色实底 = 你选错了
  - 🟢 绿色虚框 = 应该选但你没选
- 你的答案 vs 正确答案
- 解析（如题目有解析）

### 5.4 错题本

首页点击「📋 错题本」入口：
- 聚合最近 20 次考试中的错题
- 每条显示：来源考试 / 时间 / 你的答案 / 正确答案
- 点击直接跳转到对应题目的复盘

---

## 6. 其他功能

### 6.1 顺序练习

首页「🎯 顺序练习」：选择题库 → 按顺序刷题，不影响正式考试成绩

### 6.2 随机刷题

首页「🎲 随机刷题」：从题库随机抽题练习

### 6.3 我的收藏

首页「📝 我的收藏」：收藏的题目，方便复习

### 6.4 模拟考试

首页「📝 模拟考试」大按钮：选择题库进行模拟考试
- 模拟考试的成绩**不进入正式成绩单**
- 模拟考试的错题**会进入错题本**
- 可多次模拟

### 6.5 我的

底部 Tab「👤 我的」：
- 查看个人信息（姓名 / 部门 / 角色）
- 复制 openID（HR 排查问题时用）
- HR / admin 可看到「管理后台」入口
