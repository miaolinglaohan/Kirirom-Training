# 部署运维清单

> 面向开发 / 运维人员。从零开始部署一套完整环境，包含云开发配置、集合创建、云函数上传、种子数据导入、首位 admin 设置。

---

## 1. 环境准备

### 1.1 微信开发者工具

下载安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。

### 1.2 导入项目

1. 用开发者工具打开仓库根目录
2. AppID 在 `project.config.json` 中按需替换为你自己的小程序 AppID

### 1.3 开通云开发

1. 开发者工具左上角点击「云开发」
2. 新建一个云开发环境
3. 把环境 ID 写入 `miniprogram/app.js` 中 `wx.cloud.init({ env: 'xxx' })`

## 2. 数据库集合

### 2.1 需要创建的集合（共 10 个）

在云开发控制台 → 数据库中手动新建以下集合：

| 集合名 | 用途 | 创建阶段 |
|---|---|---|
| `employees` | 员工白名单（姓名/部门/角色/openid） | Phase 1 |
| `exam` | 一级试卷（字典表，1~2 条） | 原项目 |
| `subjects` | 二级题库 | 原项目 |
| `questions` | 题目 | 原项目 |
| `assessments` | HR 派发的考试 | Phase 2 |
| `examEnrollments` | 每人每场答卷快照 | Phase 2 |
| `historys` | 答题历史 | 原项目 |
| `notes` | 收藏 | 原项目 |
| `profiles` | 用户资料 | 原项目 |
| `sysConfig` | 系统设置 KV（水印/单位名） | Phase 3 |

> 也可以用 `initDB` 云函数自动创建前 6 个集合（`exam/subjects/questions/historys/notes/profiles`），但 Phase 2 之后新增的 `employees/assessments/examEnrollments/sysConfig` 需手动建。建议全部手动建一次更清晰。

### 2.2 集合权限设置

| 集合 | 权限规则 |
|---|---|
| `employees` | 仅创建者可读写（HR 通过云函数管理，不直接读写） |
| `exam` / `subjects` / `questions` | 所有用户可读（员工端直接查） |
| `assessments` | 所有用户可读（但员工端通过云函数查更可靠） |
| `examEnrollments` | 仅创建者可读写（通过云函数管理） |
| `historys` / `notes` / `profiles` | 仅创建者可读写 |
| `sysConfig` | 所有用户可读（导出 PDF 要读水印）；仅 admin 可写（通过云函数） |

> **关键**：`employees` / `assessments` / `examEnrollments` / `sysConfig` 的写操作都走云函数（云函数以服务端身份访问，不受客户端权限规则限制）。

### 2.3 数据库设计文档

详细 schema 见 [`docs/数据库设计.md`](数据库设计.md)。

## 4. 种子数据导入

### 4.1 员工白名单

在云开发控制台 → `employees` 集合 → 「导入」，选择 `data/` 下的 JSON 文件。

示例（`docs/初始员工数据.json`）：
```json
[
  { "_id": "emp001", "name": "张三", "dept": "项目部", "role": "employee", "active": true },
  { "_id": "emp002", "name": "李四", "dept": "运行检修部", "role": "employee", "active": true }
]
```

> 也可使用 `data/员工白名单模板.csv` 在 Excel 中编辑后导入。

### 4.2 题库与题目

| 文件 | 用途 |
|---|---|
| `data/subjects.json` | 题库种子数据 |
| `data/questions.json` | 题目种子数据（含单选/多选/判断） |
| `data/assessments.sample.json` | 示例考试（可直接导入联调） |

### 4.3 使用 initDB 云函数（可选）

`initDB` 云函数会自动创建集合并导入 `exam/subjects/questions` 的种子数据。第一次部署时可以调用一次：

```js
// 在开发者工具的云函数测试面板调用 initDB，无入参
```

> `initDB` 只处理原项目的 6 个集合，Phase 1~3 新增的集合仍需手动建。

## 5. 首位 admin 设置

1. 确保自己已激活（打开小程序，填姓名+部门提交）
2. 在云开发控制台 → `employees` 集合，找到自己的记录
3. 把 `role` 字段改为 `"admin"`
4. 关闭小程序重新打开，首页出现「🛠 管理后台」入口
5. 进入管理后台 → 系统设置，配置水印文字和单位名称

> 后续的 HR 可由 admin 在小程序内「员工管理」页直接升级，无需再改数据库。

## 6. 验证部署

按以下顺序验证：

1. **身份链路**：打开小程序 → 激活 → 看到「我的」页面有个人信息
2. **HR 后台**：设为 admin 后 → 看到「管理后台」入口 → 能进员工管理页
3. **题库建题**：建题库 → 录几道题 → 能看到题量统计
4. **建考试**：选题库 → 配置题量分值 → 设时间/时长/有效期 → 保存成功
5. **答题流程**：员工端看到考试 → 候考 → 进考场 → 答题 → 交卷 → 看成绩
6. **PDF 导出**：成绩中心 → 导出总分单 → 预览正常（含水印和落款）

## 7. 常见运维操作

### 7.1 查看某员工的 openID

员工打开小程序 →「我的」页面 → 长按 openID 复制 → 发给运维

### 7.2 重置某员工的考试

如需让某员工重新考试（例如成绩作废重考）：
1. 云开发控制台 → `examEnrollments` 集合
2. 搜索 `assessmentId == 考试ID` 且 `openid == 员工openid` 的记录
3. 删除该条 enrollment 记录
4. 员工即可重新进入考场

> 注意：同时也会删除该员工的历史成绩记录（`historys` 集合中对应记录），如需保留请先备份。

### 7.3 紧急下线考试

HR 在小程序「考试管理」→ 点击「结束」按钮即可。无需改数据库。

### 7.4 修改水印 / 单位名

admin 在小程序「系统设置」页直接改，无需改数据库。

### 7.5 清空测试数据重新开始

在云开发控制台删除以下集合的全部记录：
- `examEnrollments`（答卷快照）
- `historys`（答题历史）
- `assessments`（考试）
- `notes`（收藏）

> `employees` / `subjects` / `questions` 一般保留，是基础数据。
